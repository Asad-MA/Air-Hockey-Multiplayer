# Air-Hockey-Multiplayer
A web-based multiplayer game Air Hockey allows users to play with others in real time. Users can challenge, Friend Request, and chat with others in real time.
This is a web interface from where users can log in, register, chat, view the  leaderboard, make game requests, etc.
The game server code where the actual matchmaking and room creation work is done is in the other Repo, linked attached below
